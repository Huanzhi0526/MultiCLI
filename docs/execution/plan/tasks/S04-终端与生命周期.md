# S04 托管终端与进程生命周期

前置 S03 ACCEPTED。先终端闭环，再结构化协议；本阶段不引入 psmux 必需依赖。

## 子批次

1. S04-01：portable-pty/ConPTY、xterm.js、输入/输出/resize、带参数启动与多终端路由。
2. S04-02：取消与退出、Job Object/自有进程组、托盘和重开布局。
3. S04-03：背压、日志限额、长输出与句柄泄漏测试。

## 实现要求

- 创建时固定 cwd、环境差量、可执行身份；.cmd/.ps1 各有经验证的启动路径，不直接拼字符串。
- UI 只传有类型参数；终端原始字节按流处理，跨块 UTF-8 与控制序列不能简单截断。
- 每个 Run 持有自己的进程/PTY 资源；停止仅作用于自有运行。操作前核对存活与进程身份，不按进程名全局 taskkill。
- 先温和取消，超时后才结束自有树；取消推理与退出 CLI 是不同动作。
- 隐藏窗口到托盘继续；显式退出有清楚选择；崩溃清理托管树，外部进程保持。
- 不把终端日志当结构化聊天，不把无输出当 idle 的确定证据。
- 输出缓存有界，后台终端持续排空；支持退化渲染路线。

## 验收

A09/A10/A11/A20 及性能章节。Sol 用真实 Windows IME、中文/空格/特殊字符路径与支持 CLI 测试。关闭一个终端不会关闭另一个；启动/停止循环后没有孤儿子进程；外部打开同款 CLI 不受影响。

强制结束测试仅针对隔离测试进程。psmux 对照可写设计笔记，但本阶段不能顺手开启持久化实现。
