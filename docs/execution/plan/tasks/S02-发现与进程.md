# S02 安装与外部进程发现

前置 S01 ACCEPTED。DeepSeek 实现，Sol 独立真机验收。

## 子批次

1. S02-01：版本化 signature schema 与注册表；核心三款安装识别，多安装实例、已知历史残留分开。
2. S02-02：Windows 快照、命令行/路径补充、进程身份、轮询与错误降级。
3. S02-03：进程树、来源程序、会话/工作区关联证据、外部只读 UI。

## 实现要求

- 扫描只读；普通用户可访问范围，不申请常驻管理员。
- 路径与 argv 入口组合识别，禁止单个品牌字符串正则命中一切。
- pid+creation_time 防复用，父进程缺失保留断链；快照失败显示 stale，不能当全量退出。
- 外部 CLI 不要求先注册工作区才能出现；工作目录不可得时显示未关联。
- 扫描间隔可配置，批量静态数据缓存，关窗到托盘时降频。
- 已识别可信安装才做有超时版本探测；不自动下载 CLI、不执行未知 shim、不读进程环境密钥。
- 过滤/脱敏命令参数；完整敏感命令行不写日志或 DB。

## 验收

A03/A04/A05/A20。Sol 在外部 PowerShell/Windows Terminal 中启动核心 CLI，并模拟其他 CLI 启动子 CLI；至少一次真实父子进程链。Fixture 覆盖 pid 复用/权限拒绝/短命父进程/包装器/普通 node/python/参数中产品名。

目标 10 秒内发现长于扫描周期的可访问进程；短于轮询周期的进程不能保证全捕获，UI/文档必须说明，不宣称审计级全量记录。

通过标准包含：外部默认没有 send/kill 操作，重扫描无重复条目，退出后状态收敛，未知目录不误绑当前项目。
