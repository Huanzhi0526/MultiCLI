# 已知限制：0.1.0

更新于2026-11-04。以下只描述实际边界，未观察的能力不会因为源码存在而变成支持。

## 平台、安装与版本

- 当前支持目标是Windows11 x64；没有验证macOS/Linux/ARM64安装包。
- 安装器未签名，Windows可能提示未知发布者。没有现成干净VM/Sandbox；安装验证在本机隔离目录完成。
- 0.0.9→0.1.0升级夹具使用同一候选代码，仅安装版本不同，不证明真实历史版本数据迁移。
- 旧Desktop CC GUI或初期探针包不是当前安装标识；旧包卸载与任意版本并存不能据此推断已验证。
- 普通卸载保留应用数据；没有云同步、远程管理、SSH、崩溃终端保活或应用自动更新服务。

## CLI与数据覆盖

- 三核心真实样本：Codex0.166.0、Claude2.1.153、CodeBuddy2.179.3；只覆盖COMPATIBILITY.md列出的行为和版本。
- TRAE0.209.1、Gemini0.66.0只有有限发现/PTY版本与帮助证据；其他扩展产品没有完整真实交互证据。
- Codex有官方机器额度；Claude只有本地转录token，不能据此读余额；其他产品用量没有可靠出口时为unsupported。
- 真实429、真实断网、多bucket、updatedInput、超大工具输出和各产品专有interruption面仍缺真实样本。
- 历史格式随CLI变化；压缩文件物理128MiB/解压256MiB等保护预算会拒绝超大输入，不保证无限规模和即时同mtime变更。
- 外部进程按间隔采样，短进程可能漏见；发现不提供通用接管能力，不是审计级完整进程记录。
- Windows真实文件symlink边界夹具因本机权限不足未运行；没有为了测试修改安全设置。

## 运维与界面

- .ps1启动要求PowerShell7.3+。终端和结构化运行对CLI自身的信任、认证或能力限制仍需明确处理。
- 托盘菜单固定中文；主界面中文/English/한국어；未完成完整读屏器人工走查。
- 终端日志包含原始输出，备份包含已索引正文；诊断是白名单摘要，分享前仍应检查内容。
- 长时运行、低内存设备和其他真实历史规模没有充分样本。现有性能口径见[PERFORMANCE](PERFORMANCE.md)。

本机已验证安装器、来源commit、摘要和工具来源见[0.1.0版本基线](releases/0.1.0.md)。
