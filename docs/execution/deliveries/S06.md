## 3. 账户去重、freshness 与失败语义

- **一个已确认账户 = 一个池**：`pool_key = confirmed:<agent>:<fingerprint>`，两个安装 upsert 同一行，
  `installationCount` 变为 2；数据库对 `pool_key` 建唯一索引、对 `confirmed` 要求 fingerprint
  且必须引用账户行（CHECK）。
- **未确认不合并**：`pool_key = unconfirmed:<agent>:<installationId>`，界面上单独一段列出，
  永不与任何账户相加或合并。
- **新鲜度在读取时计算**：`age = now - capturedAt`；`age < 0` → `unknown`（时钟跳变），
  `age <= ttl` → `fresh`，否则 `stale`；TTL 默认 5 min，写 `expiresAt`。
- **失败不冒充 0**：失败快照 `samples=[]`、`error` 为真实 `AppError`，界面显示
  「本次没有数值：未知、过期或失败都不显示为 0」，旧数字只能从「上次成功读数」折叠区取，且带旧时间。
- **退避**：仅 `error` / `rate-limited` 记退避，`min(60s × 2^(n-1), 30min)`；提供方
  `retryAfterMs` 优先（钳 5s–1h）；退避期内刷新返回 `skipped=true`，不启动 CLI。
- **账户切换**：fingerprint 变化即新 `pool_key`，旧池保留其最后快照并随时间变 `stale`，不覆盖。
- **未安装不建池**：`installed` 取自发现注册表的 `installed` 状态（shim/残留不算），
  未安装产品刷新返回 `skipped=true / unsupported`，不写空池。

真实读数（本机，`scratch/S06/evidence-usage.json`）：

- Codex：账户 `Codex · g***@gmail.com · plus`，`identityStatus=confirmed`，`status=ok`；
  `primary` 38.0%（300 min 窗口）、`secondary` 6.0%（10080 min 窗口）、credits 一条、
  daily token 三条 + lifetime **1,754,209,270**。
- Claude：`unconfirmed` 池，转录 25 文件 / 206 记录，累计 **5,350,378** token

- CodeBuddy / TRAE：`unsupported`，`unavailableFields=[quota, tokens]`，附官方入口说明。
