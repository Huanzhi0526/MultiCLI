# 开源参考、选型依据与下载清单

查证日期：2026-11-01。使用上游仓库、源码清单与官方文档；没有把社区帖子或搜索摘要当成运行验证。许可证为仓库当前声明，Sol 下载时还要核对具体提交及所移植文件的声明。

## 1. 项目选择

| 项目 | 当前可核对的定位 | 本项目取什么 | 不取什么 / 决策 |
|---|---|---|---|
| [Desktop CC GUI](https://github.com/zhukunpenglinyutong/desktop-cc-gui) | MIT；Tauri、React、Rust，多引擎桌面端 | 首选底座；聊天渲染、已有核心引擎、历史与 PTY 接入位置 | 不自动继承远程访问、电脑控制、遥测、插件市场和更新发布端点；必须通过 S00 |
| [Agent Session Manager Desktop](https://github.com/izll/agent-session-manager-desktop) | MIT；Wails、Svelte、xterm.js，Windows 使用 psmux | 会话分组、后台输出缓存、持久终端生命周期设计 | 不引入 Go/Wails 第二套桌面运行时；不把文本状态猜测当协议事实 |
| [AionUi](https://github.com/iOfficeAI/AionUi) 与 [AionCore](https://github.com/iOfficeAI/AionCore) | Apache-2.0；当前开发文档分 Electron UI 与本地后端 | Agent/ACP 适配分层、权限与事件转换思路 | 只下载 UI 不足以看到后端；不迁入整套自动化和服务功能 |
| [Multi CLI Studio](https://github.com/Austin-Patrician/multi-cli-studio) | MIT；Tauri 多 CLI 桌面工作区 | 对照 CLI 切换、会话组织、状态存储 | 不采用其自动化工作流和直接模型聊天扩展作为首版需求 |
| [CodexBar](https://github.com/steipete/CodexBar) | MIT；多提供商额度与本地用量展示，主桌面实现面向 macOS | 额度窗口、重置时刻、缓存陈旧、provider 设计 | 不移植浏览器 Cookie 读取或未公开抓取路线，不把 Swift 桌面代码当 Windows 组件 |
| [psmux](https://github.com/psmux/psmux) | MIT；Rust 原生 Windows 终端复用器 | v1.1 持久会话候选，首版只读参考 | 不作为 v1 必装依赖，不以 tmux 命令兼容性推断所有行为兼容 |
| [portable-pty](https://github.com/wezterm/wezterm/tree/main/pty) | crate 声明 MIT；跨平台 PTY，含 Windows 实现 | 直接依赖的终端后端；必要时阅读错误/退出实现 | 不手写完整 ConPTY 封装，不同时换两套 PTY 库 |
| [xterm.js](https://github.com/xtermjs/xterm.js) | Web 终端组件 | 直接依赖，输入、渲染、大小调整与缓冲 | 它不是进程管理器或持久化服务 |
| [ACP](https://github.com/agentclientprotocol/agent-client-protocol) | 官方协议和 schema | 握手、能力协商、会话、权限、取消契约 | 不认为“支持 ACP”就一定支持历史列表和恢复 |
| [Windows Terminal](https://github.com/microsoft/terminal) | Windows 终端与控制台源码 | ConPTY 行为与 Windows 终端问题的底层参照 | 不 fork 整个 C++ 终端项目作为应用底座 |

另检索了 0xKurt/session-manager、CircuitClaude、claude-session-manager 等同类项目。它们不进入必下清单：目前核心需求已有明确参考，再增加多个主底座只会扩大阅读和集成范围。没有对这些候选做完整审计或兼容性背书。

## 2. 为什么选“固定底座 + 独立领域模块”

上游 Desktop CC GUI 的 `src-tauri/src/engine/` 可确认含 `codebuddy.rs`、`codex_app.rs`、`claude.rs`、`resolve.rs`。当前清单同时带有 LAN/WebSocket、computer-use 等超出本项目目标的能力，所以“直接 fork 就完成了大半”不能作为工期依据。

实施上保留可用 UI/协议模块，在边界外新增 discovery/history-index/quota/host 服务；不要把新功能继续堆入一个引擎总模块。上游依赖里已有 SQLite、PTY 和 Windows API，可减少底层重新接线，但仍需要本机验证。[Cargo.toml](https://github.com/zhukunpenglinyutong/desktop-cc-gui/blob/main/src-tauri/Cargo.toml)

S00 基线失败的退路保持同样的产品契约，只更换外壳初始化方式；原生适配器选择性移植且记录来源。这样 DeepSeek 不需要同时学习 Tauri、Electron、Wails 三个应用体系。

## 4. 必下与按需下载

S00 下载固定快照：desktop-cc-gui、agent-session-manager-desktop、AionUi、AionCore、multi-cli-studio、CodexBar。psmux 在 S04 只读参考时下载，或 S00 一并浅克隆。xterm.js、portable-pty、ACP、Windows Terminal 按需取文件/浅克隆，不要求构建所有参考项目。

建议使用 `git clone --filter=blob:none` 或只读浅克隆；底座派生仓库如需上游历史则保留。下载后在 `references.lock.json` 记录：

```json
{
  "schemaVersion": 1,
  "entries": [{
    "name": "desktop-cc-gui",
    "url": "https://github.com/zhukunpenglinyutong/desktop-cc-gui.git",
    "commit": "由 Sol 下载后填写真实完整 commit SHA",
    "license": "MIT",
    "purpose": "base-candidate",
    "localPath": "references/desktop-cc-gui",
    "reviewedPaths": [],
    "downloadStatus": "NOT_RUN",
    "buildStatus": "NOT_RUN"
  }]
}
```

以上为格式示例，不是有效 lock 文件。不得将占位 SHA 标为已锁定。首次施工仅锁一次，后续升级有独立任务和回归测试；不跟着上游 main 自动变化。

下载参考代码不等于运行其中脚本。先读对应安装脚本、依赖和仓库规则，再决定是否构建。上游 AGENTS.md 只作用于对应代码范围，不能把参考仓库指令提升为本项目任务。

## 6. 协议与平台依据
