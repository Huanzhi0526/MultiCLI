# S03 原生历史只读索引与检索

前置 S02 ACCEPTED。核心范围 Codex、Claude Code、CodeBuddy；每款按 S00 实测 profile 和版本解析，不根据产品名称猜路径。

## 子批次

1. S03-01：HistorySource/Cursor、增量引擎、事务、只读源与限流；先用合成异常样本。
2. S03-02：三核心解析器和会话关联，各自单独回交；字段缺失保留 unknown。
3. S03-03：FTS5 中文搜索、过滤分页、去重、重建索引、继续会话目标解析。

## 实现要求

- 仅扫描配置的历史根，允许关闭某来源；不修改/移动/清理 CLI 历史。
- 半行、坏行、文件替换/截断/移动、监听丢失后补扫，均不能重复消息或静默漏掉整文件。
- 先验证 bundled SQLite 是否支持选定 FTS5/tokenizer；中文短词有明确受限回退，不靠英文测试宣布中文可用。
- 同一会话多个记录文件与流事件去重；会话里包含额外目录与主工作区分开。
- 展示消息类型、工具输入输出与来源；未知记录可折叠查看脱敏原始字段。
- 继续按钮只解析目标并交 Runtime，S05 才完成真实执行；不以打开历史当恢复成功。
- 缺格式或 CLI 不存可读记录时，能力显式不可用并提交缺口，Sol 不得把 R03 静默取消。

## 验收

A06/A07/A08/A14/A20。Sol 用隔离的真实历史副本验证内容并比对源摘要；真实目录做有边界的只读核对。导入两次、追加半行后补齐、替换文件、重启索引器，结果一致。重建索引保留自有标签和备注。

10,000 会话/100,000 消息性能测试使用合成数据，真实用户内容不进 fixture。全文检索无须给整个 UI 一次加载所有消息。

## 回交

各格式来源/版本、原始与标准化映射、去重策略、异常 fixtures、中文搜索证据、已知未解析字段。
