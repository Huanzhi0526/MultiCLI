执行：DeepSeek 实现，Sol 验收提交。前置 S00 ACCEPTED；路径以 SOURCE-MAP.md 为准。

## 子批次

1. S01-01：Host/AgentDefinition/Installation/Workspace/Session/Run/Process 等实体、SQLite migrations、版本化 IPC 与错误类型。
2. S01-02：工作区视图、Agent 视图、会话详情、来源与能力状态；同一数据集双向访问。
3. S01-03：工作区正规化、Git worktree 分组、导出脱敏诊断、空状态及错误呈现。

## 实现要求

- Session 原生 id 带 provider/profile/host 命名空间；Run 可多次关联一个会话。
- SQLite 迁移事务化；迁移前备份自有 DB，失败保留可恢复旧数据，不能删库“升级”。
- 协议模型与持久化模型边界明确，前端不依赖 PID 当会话 id。
- 能力集合支持 unsupported 与 unverified；外部发现来源明确。
- UI 演示数据只在开发 fixture 模式存在，正常入口没有固定假会话。
- 本阶段不自建账号连接、Git 编辑器、模型聊天后端。

## 验收

A01/A02/A20；同一会话经两入口显示相同 id 与消息；不同 Host 相同路径不合并；Windows 大小写别名正常去重；两个 worktree 不误合并；目录不存在不阻断历史查看；迁移失败不损坏用户标签。

Sol 独立使用至少 3 个 Agent、2 个工作区、1 个跨目录会话做反向导航。fixture 只是本阶段领域验收，不表示真实 CLI 接入完成。
