# S06 账户用量与其余主流 CLI

前置 S05 ACCEPTED。

## 子批次

1. S06-01：AccountProfile/QuotaPool/Snapshot/UsageSample，来源与 freshness 状态、缓存和退避。
2. S06-02：Codex 官方 rateLimits；Claude/CodeBuddy 实际可得用量与官方入口；统一用量中心。
3. S06-03：Gemini、OpenCode、Qwen、Copilot、Kimi Code、Aider 的安装/进程规则与 PTY 配置；TRAE 按 S00 调查结果追加或明确限制。

## 实现要求

- 额度按账户池去重，不把同账号的两进程额度相加；身份未确认不能自动合并。
- 显示数据来源、时间、单位、有效窗口与错误。unknown/stale/unauthenticated/unsupported 不显示成 0。
- 费用与额度不同对象；账单与估算不同标识，缓存 token 不重复算。
- Codex 额度 RPC 在已有 CLI 认证范围内执行；不触发加额、邮件、充值接口。
- Claude/CodeBuddy 无已验证机器额度出口时，交付真实可得 token 和官方入口，写明余额不可读；不能抓浏览器 cookie 补齐。
- 机器可读出口未证实的斜杠命令由用户手动触发，不插到正在工作的会话里。
- signature 更新由应用版本带入或明确本地导入，使用 schema 校验，无远程任意代码插件。
- 提供自定义 CLI 的 executable、参数数组和 cwd 配置，复用 S04 PTY；参数安全验证不得因“自定义”跳过，历史和额度默认 unsupported。
- 不自动安装所发现 CLI，不自动迁移旧 Kimi 或升级 OpenCode；只报告版本边界。

## 验收

A15/A16/A17/A20。Sol 实际查看 Codex 官方额度与工作台字段，允许请求时间差但比例/窗口必须有合理对应。两会话共享池只出现一份池记录。模拟离线、429、缺 reset、null 数值、账号切换、时区显示。

9 产品族都有正负样本；扩展组至少 2 款本机真实发现+PTY 启动。其他没有真机验证的行保留 NOT_RUN，Beta 说明不把它们当全验证支持。TRAE 的产品、可执行文件和平台证据明确记录。
