## 实现要求

- 正常首次启动无 fake 数据，可引导选择已知历史来源和工作区。
- 无默认远程控制监听、上游 relay/遥测/自动更新发布点；模型 CLI 正常联网不误报为违反本地架构。
- 安装器使用 MultiCLI 独立标识，不覆盖上游产品；卸载默认保留用户数据并说明手动清理方式。
- App 数据备份与恢复限定自有目录，不打包原 CLI 凭据/完整历史。
- README 说明 managed/external/history 来源、三核心能力、9 族实际测试覆盖、额度限制、托盘与退出。
- 缺代码签名明确未签名；不为了签名降低系统安全策略。
- 把标准验证入口整合为 `scripts/verify.ps1`，准确执行存在的命令；任何跳过项显式返回报告，不永远绿灯。
